Privacy policy: joshhanson314 Mail CLI

Effective October 9, 2026.

What this app is

joshhanson314 Mail CLI is a private Google OAuth client. It lets command-line tools on my own computer read the Gmail account it was authorized for. It has one user, me. It is not offered to the public, and no one else should authorize it.

What it accesses

Only the Google data covered by the permissions shown on the consent screen at sign-in. By default that is read-only access to Gmail.

Where the data goes

  • Mail is fetched from Google straight to my computer. There is no server for this app, and nothing is stored anywhere I don't control.
  • Sign-in tokens are kept in my operating system's credential store.
  • I may use an AI assistant to help me read and organize my own mail. When I do, the messages I ask about are sent to that assistant's provider to answer my request.
  • The data is not sold, not used for advertising, and not shared with anyone else.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from myaccount.google.com/permissions.
